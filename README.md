# tehart-catalog

## Импорт фотографий из прайс-листа Avito

Эту схему использовать при следующих импортах Excel/прайс-листов. Она уже реализована в `cloudflare-worker.js` — функции `normalizePhoto()`, `extractPhotoUrls()`, `normalize()` и блок объединения товаров при импорте.

### Как извлекаются фотографии

1. При обработке строки товара Worker просматривает значения столбцов. В первую очередь подходят названия столбцов, содержащие `image`, `photo`, `фото` или `картин`; также проверяются строковые значения.
2. Из текста извлекаются URL, в том числе если они находятся в Markdown-ссылке, HTML-атрибуте или записаны как обычная ссылка.
3. В выгрузке Avito ссылка может содержать параметр `imageSlug=`. Значение параметра — путь к изображению, например `/image/...`. Из него формируется прямая ссылка:
   `https://b10.img.avito.st` + значение `imageSlug`.
4. Уже прямые ссылки на `img.avito.st` сохраняются с HTTPS.
5. Для столбцов с именами `imageUrls`, `photos`, `photo` или `images` дополнительно разбираются несколько ссылок, разделённых вертикальной чертой, переносом строки или точкой с запятой.
6. Повторяющиеся ссылки удаляются.

### Важное правило при обновлении каталога

Если в новой строке прайс-листа для уже существующего товара нет пригодных ссылок на фотографии, Worker оставляет фотографии из предыдущей записи каталога. Пустая или неполная выгрузка не должна стирать уже сохранённые фото.

### Что проверить при следующем импорте

- В исходном Excel есть столбец со ссылками, содержащими `imageSlug=` (или прямые ссылки Avito CDN).
- После импорта у товаров отображаются фотографии.
- Если в новой выгрузке у товара нет фото, ранее сохранённые фотографии остаются на месте.

**Не переписывать и не удалять эту логику при доработках импорта без отдельной проверки.** Если формат прайс-листа изменится, сначала проверить фактическое содержимое ячеек и затем точечно адаптировать извлечение URL.
